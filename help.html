Moultrie data client

A small collection client for copying your Moultrie gallery metadata into local browser storage and exporting it for analysis elsewhere.

Quick start

  1. Log in at web.moultriemobile.com and open or reload the gallery.
  2. Wait for the gallery to load, then open the extension. API auth should say Ready.
  3. Click Sync gallery. The client reconciles the full gallery so it can find new photos and pick up changes to older records.
  4. Export Photos CSV, Detections CSV, or Full JSON when you want to use the data in Splunk, Excel, Python, or another tool.

Popup controls and status fields

Help
Opens this instruction page in a new tab. It does not change or sync data.
API auth
Ready means the extension has captured the Moultrie API headers needed to make gallery requests from your current browser session. Partial means only part of the required API context was captured. Not detected means no usable API session has been observed yet. If it is not Ready, open or reload the Moultrie gallery and wait for it to finish loading.
Records stored
The number of Moultrie photo records currently stored in the extension's local IndexedDB database. This is a local count, not a live Moultrie cloud count until you sync.
Last sync
The completion time of the last successful gallery sync recorded locally by the extension.
Sync
Shows the current sync state such as Idle, Running, Complete, or Error. While a sync is running, progress and diagnostics are shown below it.
New / Updated / Unchanged
Results of the most recent reconciliation. New records had image IDs not already stored locally. Updated records already existed but their Moultrie server data changed. Unchanged records matched the locally stored server record.
Sync gallery
Requests the full Moultrie gallery page by page and reconciles every returned image record against local storage. It can collect new photos and capture later changes to older records, such as Smart Tags, favorites, or game-profile associations. It does not download the image or video files themselves.
Export photos CSV
Downloads one CSV row per stored photo record using a flattened set of useful fields for downstream tools. Nested detection details are summarized in this file.
Export detections CSV
Downloads one CSV row per detection from irTags and smartCaptureTags. A single photo can therefore produce zero, one, or multiple rows.
Export full JSON
Downloads the stored records with their full Moultrie response structure plus local collection timestamps and the last-sync summary. Use this as the highest-fidelity export and archival format.
Refresh status
Re-reads the extension's current local state and redraws the popup. It updates displayed values such as API auth, record count, last sync, and sync status. It does not contact Moultrie, start a sync, retry a failed sync, modify records, or refresh authentication by itself.
Clear local data
Deletes collected gallery records and local sync history after confirmation. It does not delete anything from your Moultrie cloud account. The currently captured API session headers are intentionally retained so a new sync can usually begin immediately if the session is still valid.

What is saved

The client saves the structured gallery records returned by Moultrie, including timestamps, camera information, tags/detections, environmental fields Moultrie returns, image/video URLs, and other record fields. It does not download or store the image or video files themselves.

The full server record is retained so fields that are not yet important can still be exported later.

Where it is saved

Collected records are stored locally in IndexedDB inside this Chrome profile. Sync status and the captured Moultrie API session headers are stored in extension-local Chrome storage. Nothing is sent to a separate server by this extension.

Because storage belongs to the Chrome profile and extension origin, another Chrome profile has separate data. Removing the extension or clearing Chrome extension/site data may remove locally stored data. Export anything you want to preserve independently.

What happens on later syncs

Each Moultrie image ID is treated as a stable record key. A later sync performs a full reconciliation:

  • New — image IDs not previously stored.
  • Updated — existing image IDs whose Moultrie record changed.
  • Unchanged — records already stored with the same server data.

This intentionally allows later Smart Tag, buck-profile, favorite, or similar server-side changes to older photos to be captured. A new camera upload later in the day simply appears as New on the next sync.

Clearing local data

Clear local data deletes the extension's collected gallery records and local sync history. It does not delete anything from your Moultrie account or cloud gallery.

The Moultrie API session information is intentionally retained when you clear collected data. If that session is still valid, the next sync can run immediately. Because the local records are gone, the next sync treats every current gallery record as New and repopulates IndexedDB.

If Moultrie authentication has expired, reload the Moultrie gallery or log in again so the extension can capture a current API session before syncing.

Authentication and privacy

The extension observes the API authentication context used by the Moultrie web application and stores the required request headers locally in Chrome extension storage. These values can include a bearer token for the current Moultrie session. They are not included in Photos CSV, Detections CSV, or Full JSON exports.

Treat your Chrome profile as sensitive while you are logged in. Logging out of Moultrie or allowing the session to expire can invalidate the captured authentication. The extension does not ask for or store your Moultrie password.

Scope

This extension is intentionally a collection and export client. Encounter grouping, weather/sunrise enrichment, trend analysis, and predictive hunting logic belong in downstream tools such as Splunk, Excel, or Python.

Troubleshooting

  • API auth is not Ready: open or reload the Moultrie gallery and wait for it to load, then click Refresh status.
  • 401 / authentication error: the captured session may be expired. Reload the gallery or log in again, then retry.
  • Record count seems old: Refresh status only refreshes the popup; use Sync gallery to query Moultrie for new or changed records.
  • After clearing data: the record count should return to zero. The next gallery sync rebuilds the local database from the cloud gallery.
